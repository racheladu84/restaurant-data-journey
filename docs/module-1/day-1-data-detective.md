The purpose of this exercise was to classify examples of data by their data type, structure and likely format.

## What I learned
I learned about the different classifications of data. Throughout this exercise, it became easier for me to spot whether something was quantitative or qualitative.
Quantitative data measures or counts something, such as a menu price or the number of orders. Qualitative data describes or labels something, such as a customer review or payment method.
I also learned that a CSV is structured in rows and columns, while JSON is semi-structured because it uses keys and values without always following a fixed table.
An order ID may contain numbers, but it is an identifier rather than a measurement.
